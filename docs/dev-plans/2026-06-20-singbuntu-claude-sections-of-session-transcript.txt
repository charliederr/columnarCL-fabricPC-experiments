  Summary

  The core insight: columns must span multiple ResNet stages, not sit as a flat layer after the backbone.

  Current architecture (broken):
  ResNet → Stage4 → Tokenize → [Flat columns] → Combiner → Classifier
                                      ↑
                             All columns see same input

  Proposed architecture:
  ResNet Stage 2 ──────────────────────────────────┐
        │                                          │
  ResNet Stage 3 ──────────────────┐               │
        │                          │               │
  ResNet Stage 4 ─────┐            │               │
        │             │            │               │
        └─────────────┼────────────┼───────────────┘
                      │            │               │
                      ▼            ▼               ▼
                [Column with K/L/B spanning all stages]
                      │
                Column output

  Key changes:
  1. K (Kernel): Concatenates features from all stages via skip connections
  2. L (Lateral): 3×3 conv refinement on mid-level features
  3. B (Bridge): Global pool from final stage, broadcast to all tokens
  4. Skip connections: Stage outputs feed directly into K pathway at each depth

  New node types needed:
  - StageTapTokenizer: Adapts each stage to a common token resolution
  - DepthSpanningColumnNode: Column with 4 input slots (stage2/3/4 + global pool)

  Phases:
  1. Stage-tapping infrastructure
  2. DepthSpanningColumn node implementation
  3. Graph construction refactor
  4. Incremental testing (single column → full config)
  5. Skip connection gradient verification

  New node: DepthSpanningColumnNode

  A cortical column that spans multiple ResNet stages with three microcolumn pathways:

  K (Kernel) Pathway - Multi-scale via skip connections

  stage4 → K_deep → concat(stage3) → K_mid → concat(stage2) → K_out
                        ↑                        ↑
                   skip connection          skip connection

  L (Lateral) Pathway - Local spatial refinement

  stage4 → L_deep → 3×3 depthwise conv → L_out

  B (Bridge) Pathway - Global context broadcast

  stage4_pool → B_deep → broadcast to all tokens → B_out

  Output

  path_scale[0] * K_out + path_scale[1] * L_out + path_scale[2] * B_out

  Factory functions:
  - create_depth_spanning_column(name, input_dim, output_dim, microcolumn_dim, grid_size)
  - create_depth_spanning_column_pool(num_columns, ...) - Creates pool of columns

  Input slots:
  - stage2: Tokenized features from ResNet stage 2
  - stage3: Tokenized features from ResNet stage 3
  - stage4: Tokenized features from ResNet stage 4
  - stage4_pool: Global pooled features from stage 4
