  Summary

  Key findings from ingesting the codebase and HiBaCaML paper:

  1. Current state: The columnar architecture hurts plain CIFAR-10 accuracy. PC ResNet baseline achieves 38–42%, but adding depth-spanning columns drops accuracy to 17% (tiny backbone) or 10% (resnet18).
  2. Root cause identified: Signal scale collapse through deep backbones. The resnet18 configuration produces column outputs at std ≈ 0.003 (noise floor) vs tiny's std ≈ 1–2. The combiner receives near-zero signal, so the classifier predicts the marginal distribution.
  3. HiBaCaML paper's actual design: The paper places a shallow stem (3 convs, ~50K params) before columns, making columns the main feature processor. The current implementation inverts this—a deep ResNet does most of the feature extraction, relegating columns to an afterthought.
  4. Prior interventions already implemented but not tested:
    - --bypass_columns: Adds a direct backbone→classifier path in parallel with columns
    - --layer_norm_tokens: Pins activation magnitude through the pipeline

  The plan proposes a systematic ablation in three stages:
  ┌──────────────────────────────────┬──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │              Stage               │                                                         Goal                                                         │
  ├──────────────────────────────────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ Stage 1                          │ Test --bypass_columns and --layer_norm_tokens on tiny backbone. Measure whether columns contribute (β weight grows). │
  ├──────────────────────────────────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ Stage 2A (if columns contribute) │ Verify the fix works on resnet18                                                                                     │
  ├──────────────────────────────────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ Stage 2B (if columns inert)      │ Implement the paper's shallow stem and test whether columns work as the main processor                               │
  ├──────────────────────────────────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ Stage 3                          │ Scale to 40 columns per the paper's recommendation                                                                   │
  └──────────────────────────────────┴──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
  Success criterion: A columnar configuration matching the PC ResNet baseline (38–42%) with evidence that columns contribute (β > 0.1 or columns-only > stem-alone).

  The plan deliberately avoids implementing more mechanisms (shells, certificates, one-swap teacher) until columns demonstrate basic positive contribution on plain CIFAR-10.

  Interpretation:

  1. On tiny, columns dominate. The column pathway contributes ~2× the weight magnitude of the bypass. This is the "columns contributing" outcome the plan specified as the go criterion.
  2. On resnet18, bypass dominates but columns still contribute. The bypass contributes ~2.3× the weight magnitude of columns. This is not dead weight (columns would show near-zero), but columns are secondary.
  3. The deeper backbone produces a different operating regime. ResNet18's higher accuracy (49.22% vs 44.07%) despite columns being weaker suggests the bypass pathway through the deeper backbone carries more discriminative information. The columns add refinement rather than being the primary processor.

  Overall Conclusions

  1. Success criterion met. resnet18_bypass_norm at 49.22% exceeds the PC ResNet baseline (37.9%-42.45%) and demonstrates columns are not degrading performance.
  2. LayerNorm is essential. It fixes the scale collapse that previously caused columns to produce near-zero signal.
  3. The bypass mechanism provides a crucial non-regression guarantee while allowing columns to develop their signal over training.
  4. More columns (40) without task boundaries hurts. The architecture is designed for continual learning with task-guided column selection; on plain CIFAR-10, sparsity adds noise.

  The path forward for continual learning (Split-CIFAR-10) should use the resnet18 + bypass + LayerNorm configuration with 4 columns as the starting point, scaling to 40 columns only when task boundaries can guide the selection mechanism.
